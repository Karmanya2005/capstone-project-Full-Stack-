# SkillPath MVP
React + Express + Node.js + MongoDB mini capstone project.

## Run locally
1. Ensure MongoDB is running locally.
2. Open this folder in VS Code.
3. In the root terminal run:
   `npm install`
   `npm run install-all`
   `npm run dev`
4. Open http://localhost:5173

API health: http://localhost:5000/api/health

This 2-hour MVP includes career selection, editable skill inventory, MongoDB persistence, server-side skill-gap scoring, and roadmap generation. It uses one local demo profile; login/admin roles and cloud deployment are not included in this rapid MVP.
